현재 프로젝트는 **데모커피 Replit**입니다.

지금까지 다음 작업이 완료됐습니다.

**중앙 ‘내 방식 QR’ 서버**
- `POST /api/ai-layout/plan` 구현
- OpenAI Responses API 연동 코드 구현
- 엄격한 입력·출력 검증
- 서버 간 Bearer 인증 구조
- 요청량 제한 및 중복 요청 방지
- Mock 테스트 17개 통과
- 실제 화면 정책은 아직 미등록
- Production Publish 미실행

**데모커피**
- 메뉴 목록 화면에 Mock AI 배치 계획 적용 구현
- 360×667에서 메뉴 이미지 비율 변환
- 390×844에서 2열 카드 → 1열 가로형 카드 변환
- 기존 상품·가격·순서·클릭 이벤트 유지
- 옵션·장바구니·가상 결제·완료 검증
- 기존 접근성 기능 회귀 테스트 통과
- 테스트 58개 통과
- SDK v0.5.31 유지
- 실제 OpenAI 호출 미실행

이번 작업은 두 프로젝트의 규격을 정확히 일치시키기 위한 **실제 구현 계약 추출 및 연동 준비**입니다.

**이번에는 읽기 전용 조사와 문서 보고만 허용합니다. 소스 수정, 서버 API 연결, 실제 AI 호출, SDK 수정, Publish는 하지 마세요.**

## 1. 실제 구현 파일 확인

데모커피에서 이번에 추가한 AI 레이아웃 관련 코드를 확인하세요.

- 화면 모델 생성 코드
- Mock 계획 주입 코드
- 계획 검증 코드
- React 레이아웃 적용 코드
- 관련 스타일
- 관련 테스트
- 개발용 `?mockAiLayout=menu-row` 처리 경로

각 코드의 실제 파일명과 함수명을 보고하세요.

가정한 이름이 아니라 **현재 소스에 존재하는 이름**을 사용하세요.

## 2. 중앙 서버와 공유할 계약 추출

아래 항목을 실제 코드에서 추출하세요.

### A. 화면 식별 정보

- 호스트 ID
- 화면 ID
- 화면 모델 버전
- 구조 버전
- 구조 해시 생성 방식
- 360×667과 390×844에서 해시가 같은지
- 화면 크기 구간 구분값

### B. 화면 요소와 그룹

- 실제 요소 ID
- 그룹 ID
- 요소 역할
- 요소 순서
- 필수 보존 요소
- AI가 변경할 수 있는 영역
- 변경할 수 없는 영역

상품명·가격·주문 상태 등 사용자별 값은 포함하지 마세요.

### C. 허용된 레이아웃 연산

실제 구현된 연산마다 다음을 정리하세요.

- 정확한 연산 이름
- 대상 그룹 또는 요소 ID
- 허용 파라미터 이름
- 허용 값 또는 범위
- 기본 레이아웃 상태
- AI 적용 레이아웃 상태
- 복원 방식

새로운 연산을 제안하는 것은 가능하지만 이번에는 실제로 구현하지 마세요.

**현재 구현된 계약과 향후 제안은 명확하게 구분하세요.**

현재 데모커피 코드에 있는 값만 이용해, 중앙 서버에 전달할 수 있는 **안전한 AI 화면 계획 요청 예시**를 작성하세요.

AI가 반환할 수 있는 정상 계획 예시도 작성하세요.

**중앙 서버 형식과 다른 부분이 발견되면 정확히 차이점을 보고하세요.**

## 4. 중앙 서버 정책 등록에 필요한 정보

중앙 서버의 다음 파일에 등록할 수 있도록 정책 정보를 정리하세요.

`server/layout-policies.ts`

필요한 정보:

- 허용 호스트 ID
- 허용 화면 ID
- 지원 구조 버전·해시
- 등록된 요소·그룹 ID
- 필수 요소
- 허용 연산·파라미터
- 크기 구간
- 계획 검증에 필요한 QR 설정 제약

중앙 서버 정책의 실제 인터페이스는 별도 프로젝트에 있으므로 추측하지 마세요.

중앙 서버 코드와 정확히 대조할 수 없는 사항은 **‘중앙 서버에서 확인 필요’**라고 명시하세요.

## 5. 일반화 가능성 검토

이번 데모커피 메뉴 화면 변환이 향후 다른 키오스크에서 재사용 가능한지 확인하세요.

특히 다음을 구분하세요.

- 키오스크 종류와 무관하게 재사용 가능한 계약
- 데모커피 메뉴에만 해당하는 그룹·요소 ID
- 무인민원발급기에서 별도로 정의해야 하는 요소
- React가 아닌 다른 프런트엔드에도 적용하려면 필요한 조건

기존 SDK가 관리하는 쉬운 말, 스마트 길잡이, 하단 조작모드, 스크롤 안내, QR 도크 및 footer는 **AI 변경 대상에서 제외**하세요.

## 6. 실제 AI 연결 전 필요한 사항

중앙 서버에 실제 정책을 등록한 뒤 데모커피에서 필요한 작업을 확인하세요.

- 데모커피 서버의 중앙 API 중계 경로
- 인증 토큰 환경 변수
- 중앙 서버 개발 URL
- 요청 전 검증
- AI 응답 검증
- 타임아웃
- 화면 이동 후 늦은 응답 무시
- 동일 화면·동일 설정의 중복 호출 방지
- 실패 시 기존 화면 유지

현재의 `?mockAiLayout=menu-row`는 개발 전용이어야 하며 일반 사용자에게 노출되지 않아야 합니다.
