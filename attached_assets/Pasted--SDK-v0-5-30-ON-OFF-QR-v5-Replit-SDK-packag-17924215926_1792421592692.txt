# 공통 SDK v0.5.30 — 아래쪽 내용 안내 ON/OFF 및 QR v5 호환성 구현

현재 프로젝트는 **데모커피 Replit**입니다.

공통 SDK 원본:
`packages/kiosk-accessibility-sdk/`

현재 안정 버전은 `@naebangsik/kiosk-accessibility-sdk@0.5.29`입니다.

이번 작업에서는 공통 SDK를 **v0.5.30**으로 올리고, QR 프로필에 새 접근성 설정인 `scrollGuidance`를 지원하도록 구현합니다.

**이번 작업에서 승인한 변경은 아래쪽 내용 안내 ON/OFF와 QR v5 호환성뿐입니다.**

중앙 QR 사이트, Production DB, 데모커피 주문 업무 로직, 무인민원발급기 업무 로직, 기존 안내 UI 디자인을 수정하지 마세요.

## 1. 새로운 설정 정의

QR 프로필의 preferences에 다음 필드를 추가할 예정입니다.

```ts
scrollGuidance: boolean
```

사용자에게 표시될 이름은 **‘아래쪽 내용 안내’**입니다.

의미:

- `true`: 스크롤할 내용이 남아 있을 때 아래쪽 내용 안내 표시
- `false`: 스크롤 안내 표시하지 않음
- 필드 누락: `false`
- QR 프로필 미적용: `false`

**명시적으로 `true`가 적용된 경우에만 스크롤 안내를 표시하는 것이 핵심 정책입니다.**

기존 QR v1~v4에는 이 필드가 없으므로 기본적으로 OFF가 되어야 합니다.

새 QR 생성 시 기본값도 OFF로 정해졌습니다. 이 기본값을 중앙 사이트에 반영하는 작업은 별도로 진행할 예정입니다.

## 2. 실제 SDK 동작

현재 SDK에는 이미 스크롤 안내 기능이 구현돼 있습니다.

기존 기능을 삭제하지 말고 표시 여부만 제어하세요.

### scrollGuidance:true

기존 v0.5.29의 스크롤 안내 동작을 그대로 유지합니다.

- 스크롤할 내용이 있을 때 표시
- 스크롤 끝에서 숨김
- 실제 스크롤 영역 기준 동작
- 일반 스크롤 콘텐츠와 겹침 허용
- 고정 QR dock과 footer는 가리지 않음
- 두 고정 조작부와의 교차 면적 0
- pointer-events:none
- 스크롤 중 위치 점프 없음
- 데모커피 주문 확인 바 회피 유지
- 안내 문구 및 디자인 유지

### scrollGuidance:false 또는 필드 누락

- 스크롤 안내가 보이지 않아야 함
- 기존 표시 중이던 스크롤 안내도 즉시 숨겨야 함
- 설정을 다시 ON 하면 현재 스크롤 위치에 맞춰 정상 표시
- OFF인 동안 불필요한 스크롤 안내 DOM·리스너·관찰자가 계속 작동하지 않도록 기존 수명 관리 구조에 맞게 정리
- OFF로 바꿔도 실제 업무 스크롤은 정상 작동
- QR dock, footer, 쉬운 말, 스마트 길잡이 기능에는 영향 없음

**안내 텍스트만 투명하게 만드는 임시 방식이나 CSS 강제 숨김으로 구현하지 마세요.**

기존 스크롤 안내 컨트롤러의 생성·갱신·정리 구조를 확인하고 가장 작은 수정으로 ON/OFF를 처리하세요.

## 3. QR v5 프로필 호환성

중앙 QR 서비스의 다음 프로필 버전은 v5로 계획되어 있습니다.

현재 SDK가 실제로 지원하는 버전 판별, 정규화, 프로필 적용 흐름을 먼저 확인하세요.

새 v5 프로필에서는 기존 v4 필드에 `scrollGuidance`가 추가됩니다.

기존 v4의 다른 설정은 모두 유지합니다.

- textSize
- buttonSize
- contrast
- easyLanguage
- smartGuide
- guideDelaySeconds
- voiceGuidance
- viewportMode
- language
- stepByStepGuidance
- conciseGuidance
- slowGuidance

필요한 타입·정규화·검증 코드만 갱신하세요.

### 필수 호환성

- v1 프로필 수신·적용 유지
- v2 프로필 수신·적용 유지
- v3 프로필 수신·적용 유지
- v4 프로필 수신·적용 유지
- v5 프로필 수신·적용 지원
- v1~v4는 scrollGuidance:false
- v5에 필드가 누락되어도 scrollGuidance:false
- v5에서 true일 때만 표시
- QR 미적용 초기 상태는 OFF
- 세션 초기화 후 OFF 복귀
- 프로필 해제 시 OFF 복귀

주의: 이전 QR에 설정값이 없다고 해서 기존에 켜져 있던 스크롤 안내를 유지하면 안 됩니다.

**현재 적용된 프로필을 기준으로 매번 ON/OFF 상태를 올바르게 갱신해야 합니다.**

## 4. QR 설정 변경 시나리오

다음 상황을 검증하세요.

A. QR 없이 키오스크 시작
→ 스크롤 안내 OFF

B. v4 QR 적용
→ 스크롤 안내 OFF

C. v5 QR, scrollGuidance:true 적용
→ 스크롤 안내 ON

D. 같은 세션에서 v5 QR, scrollGuidance:false 적용
→ 스크롤 안내 즉시 OFF

E. 다시 scrollGuidance:true 적용
→ 스크롤 안내 정상 재등장

F. 처음 화면 복귀 및 세션 초기화
→ 스크롤 안내 OFF

G. 새 세션에서 QR 없이 사용
→ 스크롤 안내 OFF

특히 C→D→E 전환에서 오래된 안내 DOM, 타이머, 이벤트 리스너가 중복 생성되거나 남지 않아야 합니다.

## 5. 기존 SDK 기능 보호

이번 수정에서 다음 기능은 절대 변경하지 마세요.

### 스크롤 안내 위치 계산

v0.5.29에서 해결한 다음 사항을 그대로 유지합니다.

- QR dock과 footer를 동시에 회피
- 일반 콘텐츠 겹침 허용
- 스크롤 끝에서 숨김
- 하단 60·70·80% 위치 안정성
- 기본 모드에서 고정 QR 버튼·footer 교차 면적 0
- 스크롤 위치 변경 중 튀지 않음

새 ON/OFF 기능 때문에 위치 계산을 재설계하지 마세요.

### 쉬운 말 안내

- 접기·펼치기 버튼 없음
- 이전·다음 및 페이지 번호 유지
- 원문 보존
- 비정상적인 1/21 과분할 재발 방지
- 자동 하단 80% 정책 유지
- 명시적 하단 60·70·80% 존중
- 기존 안내 배치와 글씨 크기 유지

### 스마트 길잡이

- 접기·펼치기 버튼 없음
- X 버튼 유지
- X 종료 시 기존 쉬운 말 페이지로 복귀
- X 종료 후 같은 단계·같은 내용의 재등장 방지
- 다음 단계·다른 안내 내용에서는 정상 예약
- 한 페이지 기본 10초 표시
- 두 페이지 기본 15초 표시
- 느린 안내 총 20초 표시
- guideDelaySeconds 10·15·20초 등장 지연
- 최대 2페이지 유지
- Smart Guide 전용 line-height:1.25 유지

### QR·세션·업무

- QR dock 정상 작동
- QR 프로필 해제·초기화
- 데모커피 주문 흐름
- 세션 종료 시 접근성 설정 초기화
- 기존 QR API 호출 방식 유지

기존 테스트 및 브라우저 fixture를 최대한 재사용하세요.

### 필수 테스트

5. v5 false → OFF

11. false일 때 실제 업무 스크롤 정상
12. 자동 하단 80% 및 명시적 60·70·80% 유지
13. Easy Language 페이지 이동 및 원문 보존
14. Smart Guide X 종료·복귀·재등장 방지
15. Smart Guide 기존 시간 정책 유지

이미 통과한 대규모 테스트를 불필요하게 반복하거나, 모든 설정 조합을 전수검사하지 마세요.

## 7. 버전 관리 및 패키징

이번 SDK 버전은 반드시 **0.5.30**입니다.

다음 항목이 모두 일치해야 합니다.

- SDK package.json version
- SDK가 노출하는 버전 상수
- tarball 내부 package.json
- release tarball 파일명
- 테스트에서 사용하는 기대 버전

출력 파일명:

`naebangsik-kiosk-accessibility-sdk-0.5.30.tgz`

기존 v0.5.29 및 v0.5.28 tarball은 수정하거나 덮어쓰지 말고 보존하세요.

필수 테스트와 빌드가 통과한 경우에만 v0.5.30 tarball을 생성하세요.

생성한 뒤 다음을 확인하세요.

- 파일 크기
- SHA-256
- 내부 주요 JS/CSS 파일 해시
- 실제 최신 dist와 패키지 내용 일치
- 다른 Replit에서 설치할 수 있는 정상 패키지인지
