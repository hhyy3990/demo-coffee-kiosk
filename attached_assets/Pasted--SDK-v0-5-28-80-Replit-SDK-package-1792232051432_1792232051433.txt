# 공통 SDK v0.5.28 — 첫 화면 하단 80% 적용 및 쉬운 말 안내 처리 수정

현재 프로젝트는 **데모커피 Replit**입니다.

공통 SDK 원본:
`packages/kiosk-accessibility-sdk/`

현재 버전:
`@naebangsik/kiosk-accessibility-sdk@0.5.28`

v0.5.28은 아직 최종 완료 릴리스가 아닌 검증용 후보입니다.

이번 작업은 사용자가 승인한 첫 화면의 접근성 표시 규칙을 수정하는 것입니다.

새로운 SDK 버전을 만들지 말고 기존 v0.5.28 후보에서 작업하세요.

## 1. 첫 화면에도 자동 하단 80% 적용

현재 SDK는 `stepId === "start"`인 화면을 자동 하단 80% 적용 대상에서 제외합니다.

그러나 사용자는 **첫 메뉴 화면에도 자동 하단 80%를 적용**하기로 결정했습니다.

다음 규칙으로 변경하세요.

| easyLanguage | 원본 viewportMode | 실제 적용 |
|---|---|---|
| false | null | 일반 화면 |
| true | null | 하단 80% |
| true | bottom 60% | 하단 60% |
| true | bottom 70% | 하단 70% |
| true | bottom 80% | 하단 80% |
| false | 명시적 하단 모드 | 원래 선택 유지 |

**첫 화면·업무 화면을 구분하지 않고 동일한 규칙을 적용하세요.**

조건:

- `stepId === "start"`에 대한 자동 80% 제외 조건 제거
- `civil.main-menu` 같은 호스트 고유 이름을 SDK에 하드코딩하지 않음
- QR의 원본 preferences를 변경하지 않음
- 쉬운 말 패널을 접어도 현재 하단 배치 유지
- 세션 종료 시 기존 초기화 정상 작동
- QR v1~v4 호환성 유지

## 2. 첫 메뉴 화면의 쉬운 말 안내

사용자는 첫 메뉴 화면에서 긴 설명이 필요하지 않다고 결정했습니다.

첫 메뉴 화면에서는 쉬운 말 안내가 켜져 있다는 사실만 간단히 보여주고 싶어 합니다.

표시 문구:

**쉬운 말 안내가 켜져 있어요.**

보조 설명:

업무를 선택하면 어려운 말을 쉽게 설명해 드려요.

동작 조건:

- 쉬운 말 활성화 상태에서만 표시
- 첫 메뉴 화면에 불필요한 여러 페이지 생성 금지
- 업무 화면으로 넘어가면 해당 단계의 기존 쉬운 말 설명 표시
- 기존 쉬운 말 접기·펼치기 동작 유지
- QR 프로필의 기존 설정값 유지

**중요: 공통 SDK에 `civil.main-menu`라는 화면 이름을 직접 추가하지 마세요.**

첫 메뉴 화면을 식별하기 위한 기존 호스트 연결 방식이나 화면 상태를 확인하세요.

첫 화면이라는 사실을 현재 SDK API가 이미 전달받고 있다면 그 정보를 활용하세요.

그렇지 않다면 SDK에 특정 키오스크 이름을 추가하는 대신, 시작 화면 안내를 호스트에서 기존 `setEasyLanguageState()`로 전달하는 방식이 가능한지 검토하세요.

데모커피에서는 기존 첫 화면의 안내 흐름에 맞게 적용할 수 있지만, 무인민원발급기 호스트 코드는 이번 작업에서 수정하지 마세요.

첫 화면의 간단한 문구 표시를 위해 새로운 공통 기능이 필요하다면 임의로 추가하지 말고 필요한 변경 사항을 보고하세요.

## 3. 스마트 길잡이와의 관계

첫 화면에는 쉬운 말 활성화 안내만 표시합니다.

첫 화면에서 기존에 제공하지 않던 새로운 스마트 길잡이 문구를 생성하지 마세요.

다른 업무 화면에서는 기존 동작을 유지합니다.

- 쉬운 말 접힘 상태에서도 스마트 길잡이 시작 시 자동 펼침
- 스마트 길잡이 종료 후 원래 쉬운 말 접힘 상태 복원
- 기존 대기 시간 유지
- 기존 표시 시간 유지
- 같은 단계의 클릭·입력·스크롤 중 조기 종료 방지

## 4. 기존 오류 재발 방지

v0.5.28에서 실제 무인민원발급기 테스트로 확인한 결과:

- 주민등록표 등본 안내: 320×844에서 4페이지
- 주민등록번호 안내: 320×844에서 5페이지
- 360×667에서 각각 6페이지·9페이지
- 390×844에서 각각 2페이지·4페이지
- 66·137페이지 비정상 분할은 재현되지 않음
- 안내 원문 보존
- 본문·버튼 잘림 없음
- 하단 모드의 안내 패널 상단 y=8px 유지

이번 변경 후에도 다음 항목을 유지하세요.

### 쉬운 말 안내

- 한 글자씩 수십·수백 페이지로 분할되지 않음
- 본문과 버튼 잘림 없음
- 원문 누락·중복 없음
- 내부 스크롤 없음
- 페이지 이동 시 패널 상단 위치 점프 없음
- 설명을 접어도 하단 80% 배치 유지

### 스마트 길잡이

- 안내 위치 점프 없음
- 접힘 상태 자동 펼침과 복원 유지
- 타이머 재시작 또는 조기 종료 없음
- 긴 문구 잘림은 여전히 미해결 검증 항목으로 유지

### 하단 스크롤 안내

- 실제 스크롤 영역 기준 하단 12px 위치 유지
- 스크롤 중 위치 점프 없음
- 끝에서 숨김, 다시 위로 이동하면 표시
- 데모커피 주문 확인 바가 있을 때 그 위 12px에 표시
- 카트 바가 사라지면 원래 위치로 복귀
- pointer-events:none 유지

### 기타

- QR 도크 정상
- 글씨·버튼·고대비 정상
- 카페 주문 단계 정상
- QR v1~v4 호환성 유지

## 5. 검증

다음 화면 크기에서 실제 브라우저 검증을 진행하세요.

- 320×844
- 360×667
- 390×844
- 1080×1920

필수 시나리오:

1. 첫 메뉴에서 쉬운 말 끔 + viewportMode null → 일반 화면
2. 첫 메뉴에서 쉬운 말 켬 + viewportMode null → 자동 하단 80%
3. 첫 메뉴에서 쉬운 말 켬 + 명시적 60% → 60% 유지
4. 첫 메뉴에서 쉬운 말 켬 + 명시적 70% → 70% 유지
5. 첫 메뉴에서 쉬운 말 켬 + 명시적 80% → 80% 유지
6. 첫 메뉴에서 간단한 쉬운 말 활성화 안내 확인
7. 업무 단계 진입 후 기존 상세 쉬운 말 안내 정상 표시
8. 페이지 전환 및 접기·펼치기 후 위치 안정성
9. 스마트 길잡이 시작·종료·원상복귀
10. 스크롤 안내 위치 및 주문 확인 바와의 관계
11. 전체 주문 완료 및 초기화

실제 첫 메뉴의 쉬운 말 안내 문구가 호스트별로 달라야 하는 부분은 별도 호스트 작업으로 구분해 보고하세요.
