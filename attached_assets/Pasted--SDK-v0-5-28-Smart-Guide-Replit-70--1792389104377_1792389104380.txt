# 데모커피 공통 SDK v0.5.28 — Smart Guide 미표시 원인 확인 및 남은 검증 완료

현재 프로젝트는 데모커피 Replit입니다.

직전 작업에서 하단 70%의 쉬운 말 과분할을 6페이지에서 2페이지로 개선하고, 기본 화면의 스크롤 안내가 고정 하단 버튼과 겹치는 문제도 SDK에서 수정했습니다.

현재 수정된 SDK 소스를 유지하세요.

이번 작업은 **Smart Guide 브라우저 테스트가 시작되지 않는 원인을 찾아 남은 회귀 검증을 완료하는 것**에 한정합니다.

새로운 기능이나 레이아웃 변경은 하지 마세요.

## 1. Smart Guide 미표시 원인 확인

현재 360×667 독립 consumer fixture에서 다음 현상이 발생했습니다.

- guideDelaySeconds: 10으로 수정됨
- 제한 시간 후에도 Smart Guide가 표시되지 않음
- 기존 쉬운 말 안내 '확인 단계', 1/3이 유지됨

먼저 다음을 조사하세요.

1. 실제 SDK가 Smart Guide 활성 상태를 받았는지
2. setGuideState() 호출 여부와 전달된 stepId
3. setEasyLanguageState() 호출과 순서
4. 현재 stage ID가 타이머 진행 중 변경되는지
5. 안내를 숨기는 모달·paused 상태가 있는지
6. 스마트 길잡이 타이머가 시작됐는지
7. 대기 중 타이머가 취소·재시작되는지
8. Smart Guide가 3페이지 이상 필요하다고 판단되어 표시 억제됐는지
9. 실제 fixture가 최신 SDK JS/CSS를 로드했는지
10. 브라우저 콘솔·SDK 경고

Smart Guide가 나타나지 않은 원인을 **SDK 결함과 fixture 결함으로 구분**해 보고하세요.

## 2. 수정 범위

원인이 테스트 fixture라면 해당 fixture 또는 브라우저 검증 스크립트만 수정하세요.

실제 SDK 결함이 확인된다면 임의로 수정하지 말고 재현 조건과 원인을 보고한 뒤 중단하세요.

다음 코드는 변경하지 마세요.

- SDK Smart Guide 표시 정책
- 10·15·20초 타이머
- 쉬운 말 페이지 분할
- 하단 70% 헤더 배치
- 스크롤 안내 위치 계산
- 데모커피·무인민원발급기 업무 로직

## 3. 필수 Smart Guide 검증

다음 실제 결제 안내 원문을 사용하세요.

stepId: certificate.payment-method

증명서 종류, 발급 부수, 표시 항목과 수수료를 확인해 주세요. 내용이 맞으면 결제 방법을 눌러 가상 결제를 진행하세요.

환경:
- 360×667
- textSize: extraLarge
- buttonSize: large
- contrast: high
- easyLanguage: true
- smartGuide: true
- viewportMode: null → 자동 80%

확인:

- 안내가 실제로 나타남
- 최대 2페이지
- 원문 누락·중복 없음
- 실제 잘림 없음
- 일반 2페이지 총 15초, 약 7.5초에 전환
- 느린 안내 2페이지 총 20초, 약 10초에 전환
- 일반 1페이지 총 10초
- 등장 전 지연 10초 유지
- 종료 후 쉬운 말 페이지 및 접힘 상태 복원
- 패널 상단 y=8px 유지
- 무한 재귀 없음

실제 스마트 길잡이가 표시된 시점을 기준으로 지속시간을 측정하세요.

## 4. 기존 수정 결과 보존

다음 결과를 유지하세요.

360×667:
- 명시적 60%: 2페이지
- 명시적 70%: 2페이지
- 명시적 80%: 4페이지
- 자동 80%: 4페이지

기본 모드 스크롤 안내:
- 고정 footer 위 12px
- footer 및 버튼과 겹침 없음
- 스크롤 끝에서 숨김

데모커피:
- 주문 확인 바 위 12px
- 전체 주문 E2E 정상

관련 테스트를 재사용하고 불필요한 중복 검증은 피하세요.
