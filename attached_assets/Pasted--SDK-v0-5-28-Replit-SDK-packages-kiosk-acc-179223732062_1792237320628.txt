# 공통 SDK v0.5.28 — 쉬운 말 안내 무한 재귀 렌더링 오류 수정

현재 프로젝트는 데모커피 Replit입니다.

공통 SDK 원본:
`packages/kiosk-accessibility-sdk/`

현재 버전은 v0.5.28 검증용 후보입니다.

이전 진단에서 360×667, 자동 하단 80%, 시작 화면 쉬운 말 안내를 렌더링할 때 SDK 내부에서 다음 오류가 재현됐습니다.

`RangeError: Maximum call stack size exceeded`

이번 작업에서는 **이 재귀 렌더링 결함과 직접 관련된 페이지 높이 계산 문제만 수정**하세요.

새로운 기능, UI 변경, 글씨 크기 변경, 안내 문구 수정은 금지합니다.

## 1. 확정된 재현 조건

- COPY_CASE=startScreen
- COPY_WIDTH=360
- COPY_HEIGHT=667
- COPY_MODE=auto
- 쉬운 말 활성화
- viewportMode=null → SDK 자동 하단 80%
- 프로필 적용 → 화면 전환 통지 → 쉬운 말 안내 상태 설정

호출 스택은 다음과 같이 나타났습니다.

`we → Z → J → J → J`

반복되는 함수는 `renderGuidancePanel()`입니다.

기존 구현은 `fitEasyLanguagePages()` 결과가 변경되면 안내 상태를 갱신하고 `renderGuidancePanel()`을 동기적으로 재호출합니다.

해당 재귀 경로에 안정적인 종료 조건이 없어서 브라우저가 스택 초과 오류를 발생시켰습니다.

## 2. 수정 원칙

다음 조건을 만족하도록 수정하세요.

1. `renderGuidancePanel()`의 무제한 동기 재귀 제거
2. 동일 원문·설정·화면 치수에서 페이지 분할이 반복적으로 재실행되지 않도록 처리
3. 실제 표시 가능한 높이를 기준으로 페이지 계산
4. 페이지 버튼 유무로 헤더 높이가 변해도 무한 반복되지 않도록 처리
5. 페이지 계산 결과가 안정화되지 않을 경우 안전하게 종료하고 진단 정보 기록
6. 원문 누락·중복·잘림을 숨기거나 성공 처리하지 않음

단순히 재귀 횟수만 제한해서 문제를 감추지 마세요.

페이지 레이아웃의 불안정한 원인과 종료 조건을 함께 해결하세요.

## 3. 기존 동작 유지

다음 기능을 변경하지 마세요.

- 쉬운 말 켜기 + viewportMode null → 첫 화면 포함 자동 하단 80%
- 명시적 하단 60·70·80% 선택 유지
- QR 원본 preferences 변경 없음
- 첫 화면의 짧은 쉬운 말 활성화 안내
- 쉬운 말 자동 페이지 분할
- 이전·다음 버튼
- 안내창 내부 스크롤 없음
- 스마트 길잡이 자동 펼침 및 접힘 복원
- 하단 모드 안내 패널 상단 약 8px 고정
- 일반 모드 안내 패널 상단 약 12px 고정
- 데모커피 스크롤 힌트의 위치 안정성
- 장바구니 바 위 힌트 표시
- QR v1~v4 호환
- 기존 주문 흐름

특히 과거에 해결했던 66·137페이지 분할과 페이지 전환 시 안내창 위치 점프가 재발하지 않아야 합니다.

## 4. 집중 재현 검증

우선 다음 순서로 진행하세요.

1. 기존 실패 fixture를 수정 전 상태로 재현
2. 실제 재귀 반복 원인과 호출 횟수 확인
3. SDK 내부에서 최소 수정
4. 같은 360×667 fixture 재실행
5. 브라우저 콘솔에 스택 초과 오류가 없는지 확인
6. 안내 원문 및 페이지 전체가 정상 표시되는지 확인
7. 안내 본문·버튼 잘림 검사
8. 페이지 전환 시 안내창 상단 Y 좌표 측정

그다음 320×844, 390×844, 1080×1920에서도 검증하세요.

특히 자동 하단 80%와 명시적 하단 80% 모두 테스트하세요.

## 5. 기존 무인민원발급기 원문 회귀

이미 확보한 기존 SDK fixture를 재사용하세요.

- `certificate.type-selection`
- `certificate.id-input`

기존 실제 안내 문구의 원문을 변경하지 마세요.

다음 결과가 유지돼야 합니다.

- 한 글자씩 66·137페이지 분할 없음
- 원문 보존
- 안내창 내부 스크롤 없음
- 제목·본문·페이지 버튼 잘림 없음
- 패널 위치 점프 없음

## 6. 나머지 회귀 검증

이번 수정이 통과하면 필요한 범위에서 다음을 재확인하세요.

- 데모커피 전체 주문 E2E

- 스마트 길잡이 타이머 유지
- 하단 스크롤 힌트 위치 안정성
- 주문 바 표시 전후 힌트 위치
- QR 도크와 QR v1~v4 호환성
- 세션 종료 후 접근성 초기화

긴 스마트 길잡이 문구 잘림은 아직 해결됐다고 보고하지 말고 별도 미검증 항목으로 유지하세요.
