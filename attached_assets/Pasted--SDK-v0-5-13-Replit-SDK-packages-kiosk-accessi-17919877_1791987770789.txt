# 데모커피 공통 SDK v0.5.13 — 실제 브라우저 검증 및 안정화

현재 프로젝트는 데모커피 Replit이며, 공통 SDK 원본은 `packages/kiosk-accessibility-sdk/`에 있습니다.

v0.5.13에서 쉬운 말과 스마트 길잡이의 공통 안내창, 접기·펼치기, 이전·다음, 숫자 카운트다운, slowGuidance 15초 및 안전한 배치를 구현했습니다.

단위 테스트 45개와 타입 검사·빌드는 통과했지만 실제 브라우저에서 새로운 안내창 기능을 충분히 검증하지 못했습니다.

**이번 작업에서는 새 기능을 추가하지 말고, v0.5.13의 실제 브라우저 동작을 검증하고 확인된 문제만 수정하세요.**

## 1. 실제 Chromium 상호작용 검증

독립 소비자 fixture 또는 테스트용 데모 화면에서 다음을 실제 클릭해 검증하세요.

- 쉬운 말 설명 3개 제공
- 이전·다음 버튼으로 설명 1/3 → 2/3 → 3/3 이동
- 2/3에서 안내창 접기
- 접힌 상태에서 스마트 길잡이 시작
- 강제 펼침이 발생하지 않는지 확인
- 스마트 길잡이 종료 후 원래 쉬운 말 설명 2/3 복원
- 접힌 상태 유지
- 다시 펼쳤을 때 동일한 설명 표시
- 단일 설명에서는 이전·다음 버튼 미표시
- 화면 단계 변경 시 새로운 단계의 설명으로 전환
- endSession() 이후 안내창 상태 초기화

## 2. 실시간 타이머 검증

SDK의 가상 타이머 테스트뿐 아니라 실제 브라우저 시간 기준으로 다음을 확인하세요.

- slowGuidance false: 스마트 길잡이 약 10초 표시
- slowGuidance true: 스마트 길잡이 약 15초 표시
- 안내창 왼쪽 위 숫자 카운트다운 감소
- 타이머 종료 후 쉬운 말 설명 복귀
- guideDelaySeconds 10/15/20초가 표시 전 대기시간으로 유지
- 빠르게 단계 전환해도 이전 타이머가 다음 안내를 종료시키지 않음

실제 시간 측정값과 허용 오차를 보고하세요.

## 3. 작은 화면과 하단 조작 검증

다음 화면을 확인하세요.

- 320×844
- 360×667
- 390×844
- 1080×1920

접근성 조합:

- 글씨 매우 크게
- 버튼 크게
- 고대비
- 하단 조작 60%
- 하단 조작 70%
- 하단 조작 80%
- 쉬운 말 + 스마트 길잡이 동시 사용

다음 요소를 안내창이 가리지 않는지 실제 클릭으로 확인하세요.

- 키패드와 입력값
- 다음·확인 버튼
- 결제 버튼
- 뒤로 가기
- 스크롤
- QR 도크

안내창의 안전한 배치가 불가능한 경우 펼친 패널 → 접힌 헤더 → 최소 안내 표시 순서로 검토하고, 핵심 조작을 방해하지 않으면서 사용자가 다시 안내를 볼 방법을 최대한 보존하세요.

불가피하게 안내창을 숨겼다면 **어떤 화면·조건에서 왜 숨겼는지** 보고하세요.

무인민원발급기 전용 CSS나 사이트별 하드코딩은 금지합니다.

## 4. 기존 기능 회귀

- QR v1~v4 파싱 및 적용
- 큰 글씨·큰 버튼·고대비
- 기존 음성 안내
- 스마트 길잡이 stepId
- QR 도크
- 하단 조작
- 완료 후 15초 자동 복귀
- 시간 연장
- 수동 처음으로
- endSession() 초기화
- 데모커피 주문·결제·영수증 선택

## 5. 검증 방식

실제 브라우저에서 수행한 항목과 단위 테스트로만 확인한 항목을 명확히 구분하세요.

브라우저 자동화가 가능한 경우 클릭·스크롤·시간 측정을 수행하고, 불가능하다면 미검증으로 보고하세요.

문제가 확인되면 SDK 공통 코드에서 원인을 수정한 뒤 관련 테스트를 추가하고 동일 시나리오를 재실행하세요.

## 6. 릴리스 처리

v0.5.13은 기존 검증 부족으로 완전히 승인된 릴리스가 아닙니다.

이번 검증에서 코드 수정이 필요하면 패키지 버전을 **v0.5.14**로 올리고 새 tarball을 생성하세요. 기존 v0.5.13 파일은 보존합니다.

수정 없이 전부 통과하면 v0.5.13을 검증 완료 상태로 보고해도 됩니다.

새 버전을 만들 경우 독립 소비자에게 해당 tarball을 설치해 검증하세요.

9. 발견된 버그 및 수정 사항

중앙 내 방식 QR, 무인민원발급기, Production DB, Publish는 건드리지 마세요.
