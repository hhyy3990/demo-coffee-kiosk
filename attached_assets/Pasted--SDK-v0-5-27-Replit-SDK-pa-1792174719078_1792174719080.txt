# 공통 SDK v0.5.27 — 하단 화면 모드 변경 시 쉬운 말 자동 페이지 재분할 오류 수정

현재 프로젝트는 **데모커피 Replit**입니다.

공통 SDK 원본은 `packages/kiosk-accessibility-sdk/`이며 현재 버전은 v0.5.26입니다.

무인민원발급기에 SDK v0.5.26을 적용해 검증하던 중 공통 SDK 결함이 발견됐습니다.

이번 작업은 **기존에 승인된 쉬운 말 자동 페이지 분할 기능의 오류 수정만** 수행합니다.

새로운 기능, 안내 문구, UI 디자인, 동작 정책은 추가하거나 변경하지 마세요. 요청 범위 밖의 작업이 필요하면 먼저 보고하고 사용자 승인을 기다리세요.

## 1. 오류 재현 조건

- 화면 크기: 320×844
- 매우 큰 글씨
- 큰 버튼
- 고대비
- 쉬운 말 활성화
- 약 2,823자 긴 시험 설명
- 일반 화면에서 하단 조작 80%로 전환

관측된 결과:

- 일반 화면: 패널 높이 632px, 24페이지
- `setViewportMode({mode:'bottom',heightPercent:80})` 호출
- 패널 높이 118px로 축소
- 기존 24페이지를 그대로 사용
- 본문과 이전·다음 버튼이 패널 밖으로 넘어가 잘림
- 같은 설명을 `setEasyLanguageState()`로 다시 전달하면 112페이지로 재분할됨

이는 공통 SDK의 표시 공간 변경 후 재분할 누락 문제입니다.

## 2. 수정할 내용

`setViewportMode()`로 가용 높이가 달라지면 SDK가 기존 쉬운 말 원문을 기준으로 페이지 분할을 다시 계산하도록 수정하세요.

다음 전환을 모두 지원해야 합니다.

- 일반 → 하단 60%
- 일반 → 하단 70%
- 일반 → 하단 80%
- 하단 60% ↔ 70% ↔ 80%
- 하단 모드 → 일반 화면

이미 구현된 화면 크기 변경 시 재분할 동작도 유지합니다.

**호스트에서 `setEasyLanguageState()`를 반복 호출하게 만드는 우회는 금지합니다.**

## 3. 기존 안내 상태 보존

재분할 과정에서 다음 동작을 유지하세요.

- 설명 원문과 순서 보존
- 텍스트 누락·중복 없음
- 안내창 자체 스크롤 없음
- 이전·다음 버튼으로 페이지 이동
- 안내창 상단 기준 위치 유지
- 접힘 상태 유지
- 스마트 길잡이 10/15초 타이머 유지
- 스마트 길잡이 종료 후 쉬운 말 복원
- 재분할 때문에 업무 화면이 바뀌거나 단계 타이머가 초기화되지 않음

페이지 수가 달라지므로 기존 페이지 번호를 무조건 유지하면 같은 문장을 다시 찾지 못할 수 있습니다.

가능하면 **사용자가 읽던 원문의 위치를 기준으로 해당 문장이 포함된 새 페이지를 표시**하세요.

단, 이 처리는 기존 설명 복원 기능의 정확성을 유지하기 위한 범위에서만 구현하고, 다른 탐색 기능은 추가하지 마세요.

## 4. 긴 설명 잘림 방지

모드 전환 후 다음을 확인하세요.

- 안내 본문이 실제 가용 높이 안에 표시됨
- 이전·다음 버튼이 잘리지 않음
- 자동 분할 페이지를 끝까지 이동 가능
- 원문을 이어 붙이면 기존 원문과 정확히 일치
- 본문 글씨 크기와 줄 간격 유지
- 접기·펼치기 버튼 44×44px 유지

기존 `overflow:hidden` 정책과 내부 스크롤 없는 구조를 유지합니다.

## 5. 실제 브라우저 검증

화면 크기:

- 320×844
- 360×667
- 390×844
- 1080×1920

화면 모드:

- 일반 화면
- 하단 60%
- 하단 70%
- 하단 80%

단순 초기 적용뿐 아니라 **같은 안내가 표시되는 도중 화면 모드를 전환**하세요.

각 전환에서 다음을 측정하세요.

1. 전환 전후 패널 높이
2. 전환 전후 페이지 수
3. 원문 보존
4. 현재 읽던 위치 보존
5. 텍스트·버튼 잘림 여부
6. 상단 안내창 Y 좌표
7. 쉬운 말 페이지 이동
8. 스마트 길잡이 전환·복원
9. 하단 업무 스크롤 및 스크롤 힌트 위치
10. 주요 업무 버튼 클릭 가능 여부

특히 **320×844 일반 → 하단 80%** 재현 사례를 반드시 실제 DOM에서 검증하세요.

## 6. 기존 정상 기능 회귀 방지

다음 기능은 변경하지 마세요.

- QR v1~v4 호환
- 하단 스크롤 안내의 업무 영역 하단 12px 고정
- 스크롤 안내 상시 표시 정책
- 상단 안내창 일반 12px·하단 모드 8px 기준
- 이전·다음·접기·펼치기 44px 버튼
- Smart Guide 단일 안내
- 동일 단계 입력 중 Smart Guide 조기 종료 방지
- 업무 단계 전환 시 안내 정리
- 완료 후 15초 자동 복귀
- QR 모달·도크
- 데모커피 메뉴·결제·주문 흐름
- 메뉴 분류 탭의 정상 스크롤과 레이어 순서
