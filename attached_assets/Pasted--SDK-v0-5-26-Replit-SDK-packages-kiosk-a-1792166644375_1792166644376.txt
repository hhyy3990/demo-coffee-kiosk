# 공통 SDK v0.5.26 — 안내창 내부 스크롤 제거 및 페이지 방식 확정

현재 프로젝트는 데모커피 Replit입니다.

공통 SDK 원본은 `packages/kiosk-accessibility-sdk/`이며 현재 버전은 v0.5.25입니다.

사용자가 안내창 동작 방식을 최종 확정했습니다.

**쉬운 말 안내는 이전·다음 버튼으로 페이지를 넘기고, 안내창 자체는 스크롤하지 않습니다.**

Smart Guide도 단일 안내만 표시합니다.

이번 작업에서는 이 정책을 공통 SDK에 반영하고, 기존 위치 안정성을 유지하세요.

## 1. 안내창 내부 스크롤 정책 제거

- 안내 패널 내부에서 별도의 휠·터치 스크롤을 사용하지 않음
- 쉬운 말 설명은 페이지 단위로 표시
- 여러 설명은 기존 이전·다음 버튼으로 이동
- Smart Guide에는 페이지 버튼 없음
- 하단 업무 화면의 스크롤은 기존대로 유지
- 내부 스크롤이 작동하지 않는다는 이유로 pointer-events:auto를 패널 전체에 적용하지 않음

기존에 발견된 긴 안내문 내부 스크롤 문제를 단순히 이벤트 허용으로 해결하지 마세요.

## 2. 긴 설명 안전 처리

설명이 패널 높이를 초과하면 텍스트가 잘리거나 업무 조작 버튼이 사라지면 안 됩니다.

다음 원칙을 적용하세요.

- 한 페이지의 설명은 짧고 이해하기 쉬운 길이를 권장
- 긴 설명은 원칙적으로 호스트가 여러 설명 페이지로 나누어 전달
- SDK가 설명을 임의로 잘라 의미를 훼손하지 않음
- 긴 입력을 감지할 수 있도록 개발용 경고 또는 검증 기능 추가
- 단순한 글자 수뿐 아니라 실제 렌더링 높이도 검사
- 정상 길이의 안내에서는 추가 스크롤이나 잘림이 없어야 함

극단적으로 긴 설명은 내부 스크롤을 다시 켜지 말고, 사용자에게 내용이 누락되지 않는 안전한 분할 방식을 설계하세요. 자동 분할을 구현한다면 문장 경계를 우선하고 원래 설명의 의미와 순서를 보존해야 합니다.

## 3. 상단 패널 위치 유지

v0.5.25에서 해결된 위치 안정성을 유지하세요.

- 일반 화면 top=12px
- 하단 조작 60·70·80% top=8px
- 이전·다음 시 위치 이동 없음
- 접기·펼치기 시 위치 이동 없음
- Smart Guide 시작·종료 시 위치 이동 없음
- 내용 길이가 달라져도 상단 기준점 고정

## 4. 하단 스크롤 안내 유지

v0.5.24에서 해결한 하단 안내는 변경하지 마세요.

- 실제 업무 영역 하단에서 12px 간격
- 아래에 내용이 남아 있으면 표시
- 스크롤 중 위치 점프 없음
- 끝에서 숨김
- 다시 위로 스크롤하면 복귀
- 주요 버튼과 겹쳐도 표시
- pointer-events:none

하단 업무 화면 스크롤과 상단 안내 페이지 이동은 독립적으로 동작해야 합니다.

## 5. 필수 테스트

320×844, 360×667, 390×844, 1080×1920의 일반 화면과 하단 60·70·80%를 검증하세요.

- 정상 길이 설명이 잘리지 않음
- 이전·다음으로 모든 설명 확인 가능
- 페이지마다 패널 Y 위치 유지
- 접기·펼치기 정상
- Smart Guide 단일 안내
- 스마트 길잡이 15초 유지
- 이전 쉬운 말 페이지 복원
- 하단 업무 화면 스크롤 정상
- 주요 업무 버튼 클릭 가능
- 매우 긴 설명에 대한 안전 처리 검증
- 데모커피 주문 전체 흐름
- QR v1~v4 호환
- SDK 소비자 회귀 테스트

## 6. 작업 범위와 릴리스

SDK 원본을 수정하고 검증을 통과하면 v0.5.26으로 릴리스하세요.

파일:

packages/kiosk-accessibility-sdk/releases/naebangsik-kiosk-accessibility-sdk-0.5.26.tgz

기존 v0.5.25 tarball은 보존합니다.

무인민원발급기 호스트, 중앙 QR, 운영 DB는 수정하지 않습니다.

AI API 추가, QR 스키마 변경, Publish는 금지합니다.
