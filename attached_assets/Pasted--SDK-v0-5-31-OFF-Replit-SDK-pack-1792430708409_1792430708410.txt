# 공통 SDK v0.5.31 — 쉬운 말 활성화 시 스크롤 안내 OFF가 무시되는 오류 수정

현재 프로젝트는 **데모커피 Replit**입니다.

공통 SDK 원본:
`packages/kiosk-accessibility-sdk/`

현재 SDK 안정 후보 버전은 `0.5.30`입니다.

이번 작업에서는 무인민원발급기 실제 Preview에서 확인된 **스크롤 안내 설정 충돌 오류 하나만 수정**하고, 새 버전 `0.5.31`로 패키징하세요.

새 기능이나 UI 변경은 승인하지 않습니다.

## 1. 실제 무인민원발급기에서 확인된 오류

v0.5.30을 설치한 무인민원발급기에서 다음 결과가 나왔습니다.

| 조건 | 기대 | 실제 |
|---|---|---|
| QR 미적용 | 스크롤 안내 OFF | OFF |
| v5 `scrollGuidance:true` | ON | ON |
| v5 `scrollGuidance:false` + 쉬운 말 ON | OFF | ON — 오류 |
| v5 `scrollGuidance` 누락 + 쉬운 말 ON | OFF | ON — 오류 |
| v1~v4 + 쉬운 말 ON | OFF | ON — 오류 |

무인민원발급기 Agent가 확인한 원인 후보는 다음과 같습니다.

- `applyProfile()`에서 `scrollGuidance:false`를 적용함
- 이후 Easy Language를 렌더링하는 경로에서 `menuHint.setEnabled(true)`를 호출함
- 그 결과 명시적으로 꺼둔 스크롤 안내가 다시 켜짐

**실제 SDK 소스에서 호출 경로를 확인하고 원인을 확정한 뒤 최소 수정하세요.**

## 2. 수정 목표

스크롤 안내는 **현재 적용된 QR 프로필에서 `scrollGuidance === true`인 경우에만** 표시되어야 합니다.

쉬운 말 안내, 스마트 길잡이, 메뉴 이동, 화면 재렌더링 등 다른 기능이 스크롤 안내의 ON/OFF 정책을 덮어써서는 안 됩니다.

다음 조건을 모두 만족해야 합니다.

- QR 없이 시작 → OFF
- QR v1~v4 → OFF
- QR v5 필드 누락 → OFF
- QR v5 `scrollGuidance:false` → OFF
- QR v5 `scrollGuidance:true` → ON
- 쉬운 말 ON + 스크롤 안내 OFF → OFF 유지
- 쉬운 말 페이지 이동 → OFF 유지
- 다른 업무 단계로 이동 → OFF 유지
- 동일 단계의 반복 상태 업데이트 → OFF 유지
- Smart Guide 등장·종료 → 설정 상태 유지
- 세션 초기화 → OFF
- 프로필 해제 → OFF

**쉬운 말 활성화와 스크롤 안내 활성화는 서로 독립적인 기능입니다.**

## 3. 최소 수정 원칙

SDK에서 `menuHint.setEnabled(...)`를 호출하는 경로를 확인하세요.

특히 다음을 점검하세요.

1. `applyProfile()`의 스크롤 안내 설정 적용
2. Easy Language 활성화·렌더링 경로
3. 메뉴 변경 및 단계 상태 변경 경로
4. 프로필 초기화 경로
5. `menuHint.setEnabled(true)`가 호출되는 모든 위치

현재 적용된 `scrollGuidance` 정책을 단일 기준으로 유지하고, 다른 기능이 임의로 안내를 켜지 못하도록 수정하세요.

단, 스크롤 안내가 명시적으로 ON인 경우에는 기존처럼 정상 표시되어야 합니다.

**금지 사항:**

- 스크롤 안내 기능 자체 제거
- Easy Language를 끄는 방식으로 우회
- `scrollGuidance:false`에서 CSS로만 숨기는 방식
- 호스트 CSS에 강제 숨김 규칙 추가
- 스크롤 안내 위치 계산 재설계
- QR dock 또는 footer 배치 변경
- 다른 접근성 기능의 ON/OFF 정책 변경

## 4. 반드시 확인할 전환 시나리오

같은 브라우저 세션에서 다음 순서로 검증하세요.

1. QR 없음 → OFF
2. v5 `scrollGuidance:true` 적용 → ON
3. Easy Language ON → ON 유지
4. v5 `scrollGuidance:false` 적용 → OFF
5. Easy Language 페이지 이동 및 업무 단계 이동 → OFF 유지
6. v5 `scrollGuidance:true` 재적용 → ON
7. v4 프로필 적용 → OFF
8. 프로필 해제·세션 초기화 → OFF

또한 다음을 확인하세요.

- OFF일 때 안내 DOM·리스너·관찰자 정리
- ON 재적용 시 정상 재연결
- 중복 안내 DOM 생성 없음
- 실제 업무 스크롤 정상
- 스크롤 끝에서 안내 숨김
- 다시 위로 스크롤하면 ON 조건에서 재표시

이전 프로필의 ON 상태가 새 프로필의 OFF 상태에 남아서는 안 됩니다.

## 5. 이전에 해결한 오류 회귀 방지

이번 수정은 스크롤 안내의 활성화 조건만 다룹니다.

다음은 변경하지 마세요.

### 스크롤 안내 위치

- QR 도크와 footer를 동시에 회피
- 고정 조작부와 교차 면적 0
- 일반 스크롤 콘텐츠와 겹침 허용
- 스크롤 끝에서 숨김
- 기존 약 12px 간격 유지
- 기본 모드와 하단 60·70·80% 지원
- 스크롤 중 위치 점프 없음

### 쉬운 말

- 접기·펼치기 버튼 없음
- 이전·다음 및 페이지 번호 정상
- 안내 원문 보존
- `1/21` 과분할 오류 재발 방지
- 자동 하단 80% 정책
- 명시적 하단 60·70·80% 유지

### 스마트 길잡이

- 접기·펼치기 버튼 없음
- X 버튼 유지
- X 종료 후 기존 쉬운 말 페이지 복귀
- 같은 단계·같은 내용에서 재등장하지 않음
- 다음 단계에서 정상 등장
- 최대 2페이지
- 기본 1페이지 10초
- 기본 2페이지 15초
- 느린 안내 20초
- 등장 지연 10·15·20초 유지

### QR·업무 기능

- QR v1~v5 호환
- 기존 설정 필드·데이터 구조 유지
- 데모커피 전체 주문 흐름
- 세션 초기화 및 설정 복원
- 기존 QR 도크 버튼 동작

## 6. 검증

기존 테스트 및 브라우저 fixture를 재사용하세요.

**최우선 테스트**

- v5 false + Easy Language true → OFF
- v5 필드 누락 + Easy Language true → OFF
- v1~v4 + Easy Language true → OFF
- v5 true + Easy Language true → ON
- Easy Language 페이지 이동 후 상태 유지
- 업무 단계 변경 후 상태 유지
- ON→OFF→ON 및 세션 초기화

**핵심 회귀 테스트**

- 390×844 기본 모드에서 스크롤 안내 ON일 때 QR dock·footer와 교차 면적 0
- 360×667 자동 하단 80%에서도 고정 버튼 겹침 없음
- Easy Language 원문 보존·페이지 이동
- Smart Guide X 종료·복귀·재등장 방지
- QR v1~v5 단위 테스트
- 데모커피 주문 E2E
- SDK 단위 테스트
- 타입 검사
- SDK 및 앱 빌드

이전에 통과한 장시간 브라우저 테스트를 불필요하게 반복하지 마세요. 다만 이번 충돌을 실제 DOM에서 확인할 수 있는 브라우저 검증은 필수입니다.

## 7. 버전 관리 및 패키징

이번 버전은 반드시 **0.5.31**로 올리세요.

다음을 모두 일치시키세요.

- SDK `package.json` version
- SDK 버전 상수
- tarball 내부 package.json
- 테스트의 기대 버전

`packages/kiosk-accessibility-sdk/releases/naebangsik-kiosk-accessibility-sdk-0.5.31.tgz`

기존 v0.5.30 tarball은 보존하세요.

현재 v0.5.30 기준:

- 크기: 90,407 bytes
- SHA-256: `4f3c337a7f8d0fffa3191d91d93659046cc3a4986e3e4c2d68ae3f911bf0a6f9`

필수 검증이 통과한 경우에만 v0.5.31 tarball을 생성하세요.

생성 후:

- 새 tarball 크기·SHA-256 기록
- 내부 주요 JS/CSS와 최신 dist 해시 일치 확인
- 패키지 설치 가능 여부 확인
- 기존 tarball 덮어쓰기 금지

검증 실패 시 새 패키지를 최종 릴리스로 보고하지 마세요.
