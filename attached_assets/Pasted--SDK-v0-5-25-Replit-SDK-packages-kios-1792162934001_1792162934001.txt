# 공통 SDK v0.5.25 — 쉬운 말·스마트 길잡이 패널 위치 점프 수정

현재 프로젝트는 **데모커피 Replit**입니다.

공통 SDK 원본은 `packages/kiosk-accessibility-sdk/`이며 현재 버전은 v0.5.24입니다.

무인민원발급기에 v0.5.24를 적용한 후 사용자가 새로운 위치 오류를 발견했습니다.

**하단 스크롤 안내는 정상 작동하지만, 상단의 쉬운 말 안내 패널이 이전·다음 페이지를 누를 때 상단 40% 공간 안에서 위아래로 크게 이동합니다.**

예를 들어 다음 페이지를 누르면 패널이 상단 공간의 아래쪽으로 이동하고, 다시 누르면 중간이나 맨 위로 이동합니다.

이번 작업은 **쉬운 말·스마트 길잡이 패널의 위치 안정화만을 목표**로 합니다.

## 1. 먼저 정확한 원인을 조사

다음 항목을 구분해서 확인하세요.

- 쉬운 말 페이지별 설명 길이 차이
- 페이지 전환 후 패널 높이 변화
- 패널 높이 변화에 따른 안전 위치 후보 재선택
- 이전·다음 버튼 클릭에 따른 배치 재계산
- Smart Guide 시작·종료 시 배치 재계산
- 접기·펼치기 시 배치 재계산
- ResizeObserver 및 MutationObserver 반응
- 고정된 상단 비조작 영역의 좌표계
- 하단 조작 viewportMode 60·70·80%
- 일반 화면 viewportMode null

페이지 내용이 달라져도 동일 업무 단계에서는 안내 패널이 불필요하게 상단·중간·하단을 오가면 안 됩니다.

## 2. 무인민원발급기와 동등한 fixture 재현

독립 SDK 소비자 fixture에 다음 조건을 구성하세요.

- 화면 390×844
- 하단 조작 60%
- 매우 큰 글씨
- 큰 버튼
- 고대비
- 쉬운 말 2~3페이지
- 서로 길이가 다른 설명 문구
- 상단 비조작 영역 40%
- 하단 스크롤 영역
- 고정 푸터 및 QR 도크

다음 동작의 실제 패널 Y 좌표를 측정하세요.

1. 쉬운 말 1페이지 표시
2. 다음 → 2페이지
3. 이전 → 1페이지
4. 다음 → 2페이지
5. 접기
6. 펼치기
7. 스마트 길잡이 시작
8. 스마트 길잡이 종료
9. 기존 쉬운 말 페이지로 복원
10. 하단 업무 화면 스크롤

각 단계마다 boundingRect.top과 bottom을 기록하세요.

단순히 안내 상태가 유지된다는 이유로 정상 처리하지 마세요.

## 3. 원하는 배치 정책

**동일 업무 단계에서 안내 패널의 기본 위치는 일정해야 합니다.**

권장 방향:

- 상단 비조작 영역 안에서 안정적인 기준 위치 사용
- 페이지 내용이 달라져도 패널 상단 Y 좌표 유지
- 안내 패널 높이는 내용에 따라 자연스럽게 변할 수 있음
- 내용이 길면 필요할 경우 패널 내부 스크롤 또는 안전한 최대 높이 적용
- 페이지 전환만으로 다른 위치 후보 선택 금지
- Smart Guide로 전환하거나 복귀해도 기준 위치 유지
- 접기·펼치기 시에도 같은 기준 위치 우선
- 화면 크기나 viewportMode가 실제로 바뀌면 필요한 재배치 허용

가능하다면 상단 여백을 일정하게 유지하는 **top-anchor 방식**을 우선 검토하세요.

단, 모든 모드에 특정 픽셀 좌표를 강제로 하드코딩하거나 업무 버튼을 가리는 방식으로 해결하지 마세요.

## 4. 쉬운 말·스마트 길잡이 상태 유지

기존 정상 기능을 유지하세요.

- 쉬운 말 즉시 표시
- 여러 설명의 이전·다음 이동
- 접기·펼치기
- 스마트 길잡이 단일 안내
- 스마트 길잡이에는 이전·다음 버튼 없음
- 10/15/20초 표시 전 대기
- 10/15초 표시 유지
- 같은 화면에서 입력·선택해도 조기 종료되지 않음
- 스마트 길잡이 종료 후 쉬운 말 페이지와 접힘 상태 복원

## 5. 하단 스크롤 안내는 수정하지 말 것

v0.5.24에서 해결된 하단 스크롤 안내 배치 구조는 유지합니다.

- 실제 스크롤 영역 하단에서 12px 간격
- 스크롤 중 위치 고정
- 더 내릴 내용이 있을 때 표시
- 스크롤 끝에서 숨김
- 다시 위로 스크롤하면 복귀
- 버튼과 겹쳐도 표시
- pointer-events: none
- 모달 스크롤 상태 정상 반영

**이번에 상단 패널을 수정하다가 하단 스크롤 안내가 다시 튀면 작업 실패입니다.**
