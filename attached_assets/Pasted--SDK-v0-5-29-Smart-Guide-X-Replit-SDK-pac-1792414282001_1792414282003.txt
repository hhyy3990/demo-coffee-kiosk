# 공통 SDK v0.5.29 — 고정 버튼 회피 및 Smart Guide X 재등장 오류 수정

현재 프로젝트는 **데모커피 Replit**입니다.

공통 SDK 원본:
`packages/kiosk-accessibility-sdk/`

무인민원발급기 실제 호스트에서 v0.5.28 최신 tarball을 설치한 뒤 다음 두 오류를 확인했습니다.

이번 작업은 **이 두 오류만 수정**합니다.

또한 사용자의 버전 관리 요청에 따라 **반드시 SDK 버전을 v0.5.29로 올리세요.**

## 1. 오류 A — 스크롤 안내가 footer를 가림

390×844 기본 모드 실제 측정:

- QR dock: Y=686~758
- QR 버튼: Y=696.50~748.50
- footer: Y=758~844
- 스크롤 안내: Y=787.61~832

결과:

- QR 버튼과 교차: 0px²
- footer와 교차: 약 9,667px²
- `처음화면`, `전화면` 버튼 글씨를 가림

기존 SDK에서는 QR dock을 가렸고, 최근 수정에서는 QR dock을 피했지만 footer를 가리게 됐습니다.

### 수정 목표

스크롤 안내를 배치할 때 다음 고정 영역을 **동시에** 고려하세요.

- SDK 생성 QR dock
- 호스트가 등록한 bottomControls
- 필요한 경우 실제 고정된 guidanceAvoidAreas

중요한 것은 개별 장애물을 순차적으로 피하다 다른 장애물 안으로 들어가지 않도록 하는 것입니다.

수정 전에 현재 위치 계산의 후보 선택·경계 조건을 확인하고, 문제가 발생하는 이유를 특정하세요.

### 성공 기준

390×844 기본 모드:

1. 스크롤 안내와 QR dock의 교차 면적 0
2. 스크롤 안내와 footer의 교차 면적 0
3. 두 고정 영역의 위쪽에서 안정적으로 표시
4. 가능하면 QR dock 위 약 12px 간격
5. 실제 스크롤 끝에서 안내 숨김
6. 스크롤 중 위치 점프 없음
7. pointer-events:none 유지
8. QR 버튼 클릭 정상

하단 70%·80%에서도 기존 정상 동작을 유지하세요.

### 절대 변경하지 않을 동작

**일반 스크롤 콘텐츠와 스크롤 안내가 겹치는 것은 정상입니다.**

카드, 입력창, 키패드, 일반 메뉴 등 스크롤되는 콘텐츠와의 겹침을 회피 대상으로 삼지 마세요.

일반 콘텐츠 padding, margin, 배치를 수정하지 마세요.

고정된 QR dock과 footer 등 실제 고정 조작부만 보호하세요.

## 2. 오류 B — Smart Guide X 클릭 후 재등장

무인민원발급기 실제 호스트에서 다음을 확인했습니다.

1. 주민등록표 종류 선택 화면
2. 쉬운 말 안내 2/2 페이지 표시
3. Smart Guide 등장
4. X 버튼을 실제 터치로 클릭
5. Smart Guide 즉시 종료
6. 쉬운 말 2/2 페이지 정상 복귀
7. **같은 업무 단계에서 약 10초 후 Smart Guide 재등장**

이 동작은 사용자가 원하지 않는 오류입니다.

### 수정 목표

X 버튼으로 종료한 Smart Guide는 **같은 업무 단계에서 다시 자동 등장하지 않아야 합니다.**

단, 다음 업무 단계로 이동하면 새로운 단계의 Smart Guide는 기존 정책에 따라 등장해야 합니다.

확인할 사항:

- X 종료가 타이머를 실제 취소하는지
- `setGuideState()` 반복 호출로 타이머가 재등록되는지
- 같은 stepId에서 닫힘 상태가 유지되는지
- 단계가 변경되면 해당 상태가 정상 초기화되는지
- 앱의 rerender로 같은 안내가 재생성되는지
- 자동 종료와 수동 X 종료의 정책이 구분되는지

### 성공 기준

- X 클릭 즉시 Smart Guide 종료
- 기존 Easy Language 페이지로 복귀
- 같은 stepId에서 30초 이상 재등장 없음
- 같은 stepId의 반복 setGuideState 호출에도 재등장 없음
- 다음 실제 stepId로 변경하면 정상 안내 예약
- 세션 초기화 후에는 새 세션 정책대로 작동
- 자동 종료 시 Easy Language 복귀 유지
- 기존 10/15/20초 등장 지연 유지
- 한 페이지 10초, 두 페이지 15초, 느린 안내 20초 표시 정책 유지
- 최대 2페이지 및 원문 보존 유지

동일 단계에서 다른 안내 내용을 의도적으로 전달하는 경우까지 무조건 차단하지 않도록 기존 state 식별 구조를 먼저 확인하세요.

## 3. 이전에 해결한 기능 보호

아래 기능은 이미 수정됐으므로 변경하지 마세요.

- Easy Language 접기/펼치기 버튼 제거
- Smart Guide 접기/펼치기 버튼 제거
- Smart Guide X 버튼 유지
- Smart Guide 종료 후 Easy Language 페이지 복귀
- Easy Language 원문 보존 및 페이지 분할
- 1/21 과분할 오류 방지
- 하단 70% 페이저 배치
- Smart Guide 2페이지 표시와 line-height:1.25
- 자동 하단 80% 정책
- QR 도크 하단 고정
- QR v1~v4 호환
- 데모커피 주문 흐름
- 세션 종료 및 초기화

## 4. 검증 방식

실제 호스트 구조를 반영한 fixture를 사용하세요.

- `main.stage` 스크롤
- `.device-footer` 고정
- SDK 생성 QR dock은 document.body 직속
- bottomControls에는 footer
- guidanceAvoidAreas에는 QR dock

390×844 기본 모드에서 다음 세 요소를 동시에 측정하세요.

- QR dock
- footer
- 스크롤 안내

**QR dock만 피했는지 확인하고 끝내지 말고, footer까지 동시에 교차 면적이 0인지 확인해야 합니다.**

하단 70%·80% 및 320×844, 360×667, 1080×1920에서도 고정 조작부 겹침을 확인하세요.

Smart Guide는 실제 X 버튼 이벤트를 통해 검증하세요.

- X 클릭 후 Easy Language 복귀
- 같은 단계 30초 이상 재등장 없음
- 같은 단계 반복 상태 업데이트에도 재등장 없음
- 다음 단계 정상 등장
- 자동 종료 후 쉬운 말 복귀
- 10/15/20초 타이머·최대 2페이지 검증

테스트 중 Smart Guide를 단순히 비활성화하거나 타이머를 영구 차단하는 식으로 성공 처리하지 마세요.
