# 공통 SDK v0.5.28 — 고정 하단 버튼과 스크롤 안내 겹침 수정 + 접기·펼치기 제거

현재 프로젝트는 **데모커피 Replit**입니다.

공통 SDK 원본:
`packages/kiosk-accessibility-sdk/`

이번 작업은 사용자가 승인한 두 가지 수정만 수행합니다.

1. 스크롤 안내가 **하단에 고정된 파란 버튼 영역**을 가리는 오류 수정
2. 쉬운 말과 스마트 길잡이의 접기·펼치기 제거, 스마트 길잡이 X 버튼 유지 및 쉬운 말 복귀

**일반 콘텐츠와 스크롤 안내가 겹치는 것은 정상 동작입니다. 이를 오류로 취급하거나 수정하지 마세요.**

## 1. 스크롤 안내 — 정확한 오류 정의

사용자가 첨부한 첫 번째 무인민원발급기 사진이 기준입니다.

화면 하단에는 파란색의 고정 버튼 영역이 있고, 그 위에 다음 안내가 겹쳐 있습니다.

“↓ 아래에도 내용이 있어요”

이 때문에 고정 버튼에 적힌 글씨를 읽을 수 없습니다.

이 고정 버튼 영역은 스크롤 가능한 일반 콘텐츠가 아니라, **스크롤을 내려도 화면에 남아 있는 고정 조작부**입니다.

따라서 스크롤 안내가 이 영역의 글씨나 버튼을 가리는 것은 명백한 오류입니다.

### 반드시 구분할 사항

**정상 동작 — 수정 금지**

- 스크롤 안내가 일반 메뉴 카드 위에 겹침
- 스크롤 안내가 증명서 선택 카드 위에 겹침
- 스크롤 안내가 주민등록번호 입력 영역이나 키패드 위에 일시적으로 겹침
- 스크롤 중 안내가 일반 콘텐츠 위에 떠 있음
- 맨 아래까지 스크롤하면 안내가 사라짐

이런 일반 콘텐츠 겹침은 스크롤 안내의 원래 동작이므로 문제가 아닙니다.

**오류 — 반드시 수정**

- 스크롤 안내가 하단 고정 파란 버튼의 글씨를 가림
- 스크롤 안내가 하단 고정 조작부를 덮음
- 화면을 스크롤해도 고정된 버튼을 계속 가리는 위치에 안내가 있음

이번 작업에서는 **고정 조작부와의 겹침만 수정**하세요.

## 2. 스크롤 안내 수정 방법

먼저 첨부한 첫 번째 사진의 파란색 고정 영역이 실제 DOM에서 어떤 요소인지 확인하세요.

무인민원발급기 호스트는 기존에 다음 정보를 SDK에 등록합니다.

- scrollArea: `main.stage`
- bottomControls: `.device-footer`
- 추가 안내·버튼 관련 layout region

하지만 사용자가 보여준 파란색 고정 버튼 영역이 정확히 `.device-footer`인지, SDK가 생성한 별도 고정 영역인지, 호스트의 다른 요소인지는 확인이 필요합니다.

**파란 영역의 실제 DOM 요소, position 속성, bounding rect, SDK 등록 정보를 확인한 뒤 수정하세요.**

수정 원칙:

1. 스크롤 안내의 위치는 실제 스크롤 영역을 기준으로 계산
2. 하단 고정 조작부가 있으면 그 위쪽에 안내 배치
3. 고정 조작부와 약 12px 간격 유지
4. 기존 footer·주문 확인 바와의 간격 처리 유지
5. 스크롤 중 안내 위치가 튀지 않음
6. 실제 스크롤 끝에서는 안내 숨김
7. pointer-events:none 유지
8. 일반 콘텐츠와의 겹침은 그대로 허용

### 절대 금지

- 일반 카드나 일반 텍스트를 장애물로 등록
- 콘텐츠와 겹치지 않도록 스크롤 안내를 계속 이동
- 일반 콘텐츠에 불필요한 padding-bottom 추가
- 모든 버튼·카드 위로 안내를 밀어 올리는 계산
- 스크롤 안내를 영구적으로 숨기기
- 스크롤 안내를 별도의 큰 배너로 변경
- 호스트 CSS에 임의 bottom 값 추가
- 정상인 일반 콘텐츠 겹침까지 없애려는 자동 보정 추가

**고정 조작부만 보호해야 합니다. 일반 스크롤 콘텐츠를 보호 대상으로 확대하지 마세요.**

SDK만으로 실제 파란 고정 영역을 식별할 수 없다면, 필요한 최소 호스트 연결 정보를 보고하고 추가 수정은 사용자 승인 전까지 보류하세요.

## 3. 쉬운 말 — 접기·펼치기 제거

사용자는 쉬운 말 안내가 사용할 상단 공간을 확보한 현재 구조에서 접기·펼치기 기능이 불필요하다고 결정했습니다.

다음만 변경하세요.

- 쉬운 말 안내의 접기·펼치기 버튼 제거
- 쉬운 말 안내는 표시 중 항상 펼쳐진 상태 유지
- 기존 이전·다음 페이지 버튼 유지
- 페이지 번호 유지
- 기존 설명 제목·본문 그대로 유지
- 하단 60·70·80% 배치 유지
- 기존 쉬운 말 분할 결과를 불필요하게 변경하지 않음

버튼 제거 후 남는 공간 때문에 페이지 분할이 달라질 수 있으므로, 실제 원문 보존·잘림·페이지 수 안정성을 다시 검증하세요.

**쉬운 말 안내에 X 버튼을 새로 만들지 마세요.**

## 4. 스마트 길잡이 — 접기·펼치기 제거, X 버튼 유지

사용자가 보고한 기존 오류:

스마트 길잡이 상단의 접기 버튼을 누르면 문구만 사라지고 안내창은 계속 남아 있습니다.

이번에는 해당 동작을 수정하는 대신 **접기·펼치기 기능 자체를 제거**합니다.

변경 사항:

- 스마트 길잡이의 접기·펼치기 버튼 제거
- 기존 X 버튼 유지
- 스마트 길잡이가 표시되는 동안 안내창은 항상 펼쳐진 상태
- 기존 스마트 길잡이 본문·타이머·페이지 전환 유지

### X 버튼 동작

쉬운 말 안내를 보고 있는 도중 스마트 길잡이가 나타났다면:

1. 쉬운 말 안내가 표시됨
2. 스마트 길잡이 등장
3. 쉬운 말 안내 대신 스마트 길잡이가 표시됨
4. 사용자가 스마트 길잡이의 X 버튼을 누름
5. 스마트 길잡이가 즉시 종료됨
6. **기존 쉬운 말 안내가 다시 표시됨**
7. 가능하면 스마트 길잡이 등장 직전의 쉬운 말 페이지를 유지

스마트 길잡이가 시간이 지나 자동 종료된 경우에도 기존 쉬운 말 안내로 복귀해야 합니다.

쉬운 말 안내가 비활성화돼 있었다면 X 버튼을 눌러도 쉬운 말 안내를 새로 켜지 마세요. 기존 안내 상태로 돌아가면 됩니다.

X 버튼을 누른 뒤 같은 단계에서 스마트 길잡이가 즉시 다시 등장하거나 기존 타이머가 남아 재등장하지 않도록 확인하세요.

단, 실제 업무 단계가 바뀌면 기존 단계별 스마트 길잡이 동작은 정상적으로 이어져야 합니다.

## 5. 기존 정책 유지

스마트 길잡이:

- 짧은 안내: 1페이지, 10초
- 긴 안내: 최대 2페이지, 총 15초
- 느린 안내: 최대 2페이지, 총 20초
- 2페이지 일반 안내: 약 7.5초 후 자동 전환
- 2페이지 느린 안내: 약 10초 후 자동 전환
- 등장 전 지연: guideDelaySeconds 10·15·20초 유지
- 원문 생략·자동 요약 없음
- 기존 상단 8px 위치 유지

쉬운 말:

- 자동 하단 80% 유지
- 명시적 하단 60·70·80% 유지
- 원문 보존
- 비정상적인 1/21 과분할 재발 금지
- 70%에서 개선한 페이지 조작부 배치 유지
- 페이지 이동 시 총 페이지 수 안정성 유지

QR·업무:

- QR v1~v4 호환 유지
- QR 도크 유지
- 데모커피 주문 흐름 유지
- 세션 종료·접근성 설정 초기화 유지

## 6. 브라우저 회귀 검증

화면 크기:

- 320×844
- 360×667
- 390×844
- 1080×1920

접근성 모드:

- 기본 모드
- 명시적 하단 60%
- 명시적 하단 70%
- 명시적 하단 80%
- 쉬운 말 활성화 + viewportMode:null → 자동 80%

### 스크롤 안내

반드시 두 종류를 구분해서 측정하세요.

A. 일반 스크롤 콘텐츠와의 겹침

- 정상으로 허용
- 일반 콘텐츠 겹침만을 이유로 실패 처리 금지

B. 고정 하단 조작부와의 겹침

- 반드시 교차 면적 0
- 고정 영역 위 약 12px 간격
- 실제 스크롤 끝에서 숨김
- 스크롤 중 위치 안정성

특히 첫 번째 스크린샷처럼 파란 고정 영역과 스크롤 안내가 겹치는 상황을 consumer fixture에서 재현하세요.

기존 `.device-footer` 외에 고정 영역이 있다면 실제 등록·인식 여부를 확인하세요.

### 접기·펼치기 제거

- 쉬운 말에 접기 버튼 없음
- 스마트 길잡이에 접기 버튼 없음
- 스마트 길잡이에는 X 버튼 존재
- 이전·다음 및 페이지 번호 유지
- Smart Guide X 클릭 시 기존 Easy Language 복귀
- Smart Guide 자동 종료 시 기존 Easy Language 복귀
- X 클릭 이후 같은 단계에서 불필요한 재등장 없음
- 긴 설명 2페이지 자동 전환 정상
- 쉬운 말·스마트 길잡이 본문 잘림 없음

테스트에서 기존 접힘 상태 복원을 전제로 하는 검사는 **새로 승인된 항상 펼침 정책에 맞게 수정**하세요.

정상 동작을 검증하는 테스트 자체를 제거하는 방식으로 통과 처리하지 마세요.

## 7. 특히 보호해야 할 과거 오류

이전 수정 과정에서 다음 문제가 반복됐습니다.

- 쉬운 말이 1/21처럼 과분할됨
- 한 글자·한 단어씩 페이지가 나뉨
- 접기·펼치기 후 전체 페이지 수가 바뀜
- Smart Guide가 4페이지 필요로 계산돼 미표시됨
- Smart Guide 본문이 20px 잘림
- Smart Guide 표시 시간이 초기화됨
- 상단 패널 위치가 점프함
- 스크롤 안내가 footer 버튼과 겹침
- 스크롤 안내가 스크롤 중 위아래로 튐
- 같은 SDK 버전인데 오래된 tarball이 설치됨
- SDK 렌더링 무한 재귀 오류

위 항목들이 재발하지 않았는지 실제 브라우저에서 확인하세요.

특히 Smart Guide 전용 line-height:1.25 복원 규칙을 유지하세요.
