# 내 방식 QR SDK v0.3.2 — 화면 단순화 제거 및 프로필 스키마 v2 적용

현재 데모커피 프로젝트에는 `@naebangsik/kiosk-accessibility-sdk@0.3.1`이 구현되어 있습니다.

중앙 '내 방식 QR' 프로젝트에서는 '화면 단순화' 기능을 제거하고 신규 프로필 스키마를 v2로 변경했습니다. 해당 중앙 서비스의 변경 사항은 아직 공개 배포되지 않았습니다.

이번 작업에서는 SDK와 데모커피를 새 프로필 규격에 맞추고, 새로운 설치형 SDK v0.3.2를 제작해 주세요.

## 1. 화면 단순화 기능 완전 제거

기존 설정 필드의 정확한 이름은 `simplifiedLayout`입니다.

다음 위치에서 해당 기능을 제거해 주세요.

- SDK 프로필 타입과 기본 설정
- SDK 프로필 검증
- 화면 단순화 관련 CSS 클래스 및 스타일
- 화면 단순화에 따른 레이아웃 변경 로직
- 화면 단순화 관련 설명 및 테스트
- 데모커피의 접근성 설정 UI
- 데모커피의 QR 설정 상세 표시
- 데모커피의 단순 화면 전용 분기와 메뉴 탐색 조건

단, 메뉴 탐색 기능이 접근성 설정과 무관하게 유용하다면 일반 기능으로 유지할 수 있습니다.

**기존 메뉴와 상품, 필수 안내 문구를 삭제하거나 숨기지 마세요.**

## 2. 프로필 스키마 v2 지원

중앙 서버의 새 프로필 규격을 기준으로 SDK의 타입과 검증 함수를 수정해 주세요.

- `schemaVersion: 2` 지원
- `simplifiedLayout` 제거
- 다른 접근성 설정 필드와 값은 기존 규격 유지
- 중앙 API 응답 구조 자체는 임의로 변경하지 않기
- 새 프로필을 정확히 검증하고 적용하기
- 잘못된 응답을 정상 프로필로 처리하지 않기

중앙 서비스의 변경 내용이 현재 프로젝트에 없으므로, 기존에 확인된 필드와 중앙 프로젝트의 작업 보고를 기준으로 필요한 부분을 구현하되, 확인할 수 없는 응답 형식을 임의로 가정하지 마세요.

프로필 응답에 `schemaVersion`이 포함되는 위치와 실제 설정 객체의 구조를 현재 SDK 및 중앙 API 명세에서 확인해 주세요.

## 3. 데모커피 업데이트

기존 데모커피의 주문 기능과 디자인은 유지해 주세요.

- 시작 화면
- 메뉴 선택
- 옵션 선택
- 장바구니
- 주문 확인
- 가상 결제
- 주문 완료
- 세션 초기화

화면 단순화 때문에 별도로 분기된 UI만 정리하고, 일반 화면에서도 모든 메뉴가 표시되도록 유지해 주세요.

QR 스캐너, 직접 입력, 중앙 프로필 조회 기능을 유지합니다.

## 4. 기존 SDK 기능 보존

다음 기능은 삭제하거나 변경하지 마세요.

- QR 카메라 스캔
- QR 공식 주소·토큰 검증
- 중앙 프로필 조회 인터페이스
- 큰 글씨·큰 버튼
- 고대비
- 하단 조작
- 스마트 길잡이
- 음성 안내
- 세션 종료 초기화
- 반응형 확대 기준 재계산
- 텍스트 잘림·버튼 겹침 진단
- 안전한 자동 레이아웃 보정과 롤백

특히 하단 조작 기능은 향후 스마트폰 한손 모드처럼 화면을 아래쪽으로 이동·축소하는 방식으로 재설계할 예정입니다.

**이번 작업에서 하단 조작 기능을 새로 구현하거나 변경하지 마세요.**

## 5. 호환성 및 안전성

중앙 공개 사이트는 아직 구형 프로필을 반환할 수 있습니다.

따라서 다음 두 가지를 구분해서 테스트해 주세요.

A. 새 중앙 스키마 v2 프로필 적용

B. 현재 공개 중앙 서버의 구형 프로필에 대한 처리

구형 프로필을 지원하지 않는다면 정상 적용되는 것처럼 표시하지 말고 명확한 오류 안내를 제공해 주세요.

다만 신규 SDK의 정식 프로필 타입에 제거된 `simplifiedLayout` 설정을 계속 남겨두지는 마세요.

구형 프로필의 지원 여부와 중앙 사이트 배포 전후 영향을 완료 보고에 명확히 설명해 주세요.
