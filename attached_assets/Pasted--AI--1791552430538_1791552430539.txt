현재 '데모커피' 카페 키오스크에서 스마트 길잡이의 상황 판단 오류를 발견했습니다. 또한 현재 쉬운 말과 스마트 길잡이 기능이 실제 AI 모델을 이용하는지 확인하고 싶습니다.

이번 작업에서는 스마트 길잡이 오류를 수정하고 AI 연동 현황을 조사해 주세요.

## 1. 현재 AI 기능 구현 상태 조사

다음 사항을 확인해 주세요.

- 쉬운 말 기능이 사전에 작성한 문구를 교체하는 방식인지, 실제 AI 모델을 호출하는지
- 스마트 길잡이가 고정 규칙과 문구로 작동하는지, AI 모델을 호출하는지
- OpenAI API, Replit AI Integrations 또는 다른 AI 모델 제공 서비스가 현재 연결되어 있는지
- AI 호출 코드, 사용 모델, 환경변수, API 호출 경로가 실제로 존재하는지
- 현재 어떤 기능에서 모델 추론이 실행되는지

코드에서 확인된 사실만 보고하고, AI 모델 연결 여부를 추측하지 마세요.

API 키나 비밀값은 출력하지 마세요.

이번 작업에서는 새로운 AI API를 연결하지 마세요.

## 2. 스마트 길잡이 상황 판단 오류 수정

현재 다음 상황에서 부적절한 안내가 표시됩니다.

1. 사용자가 아메리카노를 선택합니다.
2. 옵션을 선택하고 '담기'를 누릅니다.
3. 메뉴 선택 화면으로 돌아옵니다.
4. 하단 장바구니에는 상품 1개와 '주문 확인' 버튼이 표시됩니다.
5. 15초간 조작하지 않으면 여전히 메뉴와 옵션을 고르라는 안내가 나옵니다.

이 상황에서는 장바구니에 상품이 담겨 있다는 사실을 반영해 다음과 같이 안내해야 합니다.

"음료를 담았어요! 주문을 마치려면 아래 '주문 확인' 버튼을 눌러주세요."

그리고 실제 '주문 확인' 버튼을 강조해 주세요.

## 3. 스마트 길잡이 판단 우선순위 개선

무조작 감지가 발생하면 단순히 현재 페이지 이름만 확인하지 말고, 실제 주문 상태를 함께 확인해 주세요.

특히 메뉴 화면에서 다음 우선순위를 적용합니다.

- 옵션 선택 창이 열려 있다면 현재 옵션 선택 상태와 담기 버튼을 안내
- 옵션 창이 닫혀 있고 장바구니에 상품이 1개 이상 있다면 주문 확인 버튼 안내
- 장바구니가 비어 있다면 메뉴 선택 안내
- 추가 메뉴 탐색 기능을 사용 중인 경우에는 다음 메뉴 위치를 안내

장바구니에 상품이 있어도 사용자가 추가 주문할 수 있어야 합니다. 주문 확인을 자동 실행하거나 화면을 자동 전환하지 마세요.

## 4. 버튼 강조 기능

- 스마트 길잡이가 안내하는 실제 버튼에 강조 테두리 또는 배경을 적용
- 현재 다음 행동의 actionId를 기준으로 올바른 버튼을 강조
- 안내 말풍선은 가능하면 해당 버튼 가까이에 표시
- 안내가 버튼을 가리지 않도록 배치
- 사용자가 해당 버튼을 누르면 길잡이 종료
- 새로운 주문 단계로 이동하면 타이머와 안내 상태 초기화
- 음성 안내가 켜져 있으면 올바르게 수정된 문구를 읽도록 처리

## 5. 자동 테스트

다음 상황을 각각 테스트해 주세요.

1. 장바구니가 비어 있는 메뉴 화면에서 15초 무조작
2. 옵션 선택 창에서 15초 무조작
3. 상품 1개를 담고 메뉴 화면으로 돌아온 뒤 15초 무조작
4. 상품 2개를 담고 메뉴 화면으로 돌아온 뒤 15초 무조작
5. 장바구니 화면에서 결제를 진행하지 않고 15초 무조작
6. 안내 표시 후 실제 대상 버튼 클릭
7. 안내를 닫거나 단계가 변경된 후 타이머 초기화
8. QR 프로필에 저장된 길잡이 사용 여부 및 10/15/20초 설정 반영

특히 3번과 4번 상황에서는 '메뉴를 선택해 주세요'라는 안내가 나오지 않아야 합니다.
