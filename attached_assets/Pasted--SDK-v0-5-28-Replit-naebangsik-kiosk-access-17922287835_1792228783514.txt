# 무인민원발급기 — SDK v0.5.28 후보 설치 및 실제 오류 재검증

현재 프로젝트는 무인민원발급기 Replit입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.28.tgz`는 데모커피 프로젝트의 공통 SDK 원본에서 빌드한 **검증용 후보 패키지**입니다.

현재 설치된 SDK v0.5.27을 v0.5.28 후보로 업데이트하고, 실제 QR 테스트에서 발견됐던 오류가 해결됐는지 확인하세요.

이번 작업은 설치 및 검증만 수행합니다.

**새로운 기능이나 안내 문구, 디자인, 업무 로직은 변경하지 마세요.**

## 1. SDK 설치

- 기존 v0.5.27 tarball 보존
- 첨부된 SDK v0.5.28 설치
- package.json과 lockfile 갱신
- 실제 브라우저 런타임 버전 확인
- 타입 검사 및 빌드

호스트 코드와 CSS는 변경하지 마세요.

## 2. 실제 쉬운 말 오류 재검증

기존 실제 QR 테스트에서 발생한 문제:

- 주민등록표 등본 선택: 쉬운 말 66페이지
- 주민등록번호 입력: 쉬운 말 137페이지
- 한 글자씩 분할됨
- 일부 안내 문구 잘림

실제 호스트에서 기존 안내 문구를 그대로 사용하세요.

우선 검증 조건:

- 320×844
- 매우 큰 글씨
- 큰 버튼
- 고대비
- 쉬운 말 켜기
- 스마트 길잡이 켜기
- 하단 조작 80%

주민등록표 등본 선택 화면과 주민등록번호 입력 화면을 실제 브라우저에서 열어 검증합니다.

확인 사항:

1. 쉬운 말 전체 페이지 수
2. 한 글자 단위 분할 여부
3. 원문 누락·중복 여부
4. 본문 및 버튼 잘림 여부
5. 상단 안내창 위치
6. 이전·다음 페이지 이동
7. 기존 접힘 상태 보존

320×844 결과가 정상이면 360×667, 390×844에서도 확인하세요.

## 3. 자동 하단 80% 검증

다음 두 경우를 구분해서 테스트하세요.

### QR에 하단 조작이 없는 경우

- easyLanguage: true
- viewportMode: null

예상 결과: SDK가 실제 업무 화면에 하단 80%를 자동 적용

### QR에 하단 70%가 지정된 경우

- easyLanguage: true
- viewportMode: bottom 70%

예상 결과: 사용자의 70% 선택을 유지

동일한 방식으로 명시적 60%, 80%도 확인합니다.

QR 원본 설정은 변경하지 마세요.

## 4. 스마트 길잡이 오류 검증

다음 문제를 확인하세요.

### 긴 안내 문구 잘림

기존 실제 스마트 길잡이 문구를 그대로 사용하여 하단 80%에서 표시해 보세요.

- 문구 전체가 보이는지
- 본문이 패널 하단에서 잘리는지
- 패널 상단 위치가 유지되는지

### 접힘 상태 자동 복원

1. 쉬운 말 안내를 접기
2. 스마트 길잡이 대기
3. 스마트 길잡이 시작 시 자동 펼침
4. 기존 안내 문구 정상 표시
5. 스마트 길잡이 종료
6. 쉬운 말의 원래 접힘 상태 복원

기존 타이머 정책도 유지해야 합니다.

## 5. 기존 오류 재발 검사

다음을 반드시 확인하세요.

- 쉬운 말 페이지 이동 시 패널 위치 점프 없음
- 스마트 길잡이 전환 시 패널 위치 점프 없음
- 스크롤 중 하단 안내 위치 점프 없음
- 스크롤 끝에서 안내 숨김
- 실제 스크롤 소유자 기준 하단 12px 간격
- QR 도크 정상
- 큰 글씨·큰 버튼·고대비 정상
- 기존 업무 버튼 클릭 가능
- 완료 후 자동 복귀·접근성 초기화 유지

특히 페이지 전환 과정에서 패널 상단이 약 18px에서 8px로 이동하는 현상이 재발하는지 확인하세요.

## 6. 실패 시 대응

SDK 공통 문제라면 무인민원발급기에서 수정하지 마세요.

문제가 발생하면 다음을 기록하세요.

- 화면 크기
- 접근성 설정
- 업무 stepId
- 실제 안내 원문
- 패널·헤더·본문·버튼 높이
- 현재 페이지 수
- 본문 잘림 픽셀
- 패널 상단 Y 좌표

그리고 데모커피 공통 SDK에서 수정해야 할 문제로 보고하세요.

호스트 CSS 우회나 SDK 내부 수정은 금지합니다.

## 7. 검증 이후

위 오류가 해결되었다면 기존 QR v1~v4, 주민등록등본 발급·결제·인쇄·완료·초기화의 전체 회귀 검증을 진행하세요.

오류가 재현되면 해당 지점에서 중단하고 원인을 보고하세요.

검증 성공 전에는 v0.5.28을 최종 릴리스로 취급하지 마세요.
