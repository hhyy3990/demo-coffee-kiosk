# 공통 SDK v0.5.28 — Smart Guide CSS 회귀 최소 수정 및 패키징

현재 프로젝트는 **데모커피 Replit**입니다.

직전 진단에서 스마트 길잡이가 360×667 자동 하단 80%에서 표시되지 않는 정확한 원인을 확인했습니다.

현재 SDK의 좁은 안내창 CSS에서 Smart Guide에 적용되던 `line-height: 1.25`가 누락되어 기본값 `1.5`가 적용되는 회귀 오류입니다.

이번 작업에서는 **이 CSS 회귀만 최소 수정하고 기존 검증을 완료한 뒤 tarball을 생성**하세요.

새 기능이나 다른 레이아웃 변경은 하지 마세요.

## 1. 허용된 수정

공통 SDK의 Smart Guide 전용 CSS에 다음 규칙을 복원하세요.

```css
.a11y-guide-tight.a11y-guide-smart .a11y-guide-copy {
  line-height: 1.25;
}
```

기존 Easy Language 전용 규칙은 유지하세요.

다음 사항을 변경하지 마세요.

- 쉬운 말 70% pager 헤더 배치
- 쉬운 말 페이지 계산
- 스크롤 안내 위치 계산
- Smart Guide 최대 2페이지 정책
- Smart Guide 10·15·20초 표시 시간
- 안내 원문
- QR 설정 스키마
- 호스트 업무 코드

## 2. Smart Guide 실제 문구 검증

조건:

- 360×667
- extraLarge 글씨
- 큰 버튼
- 고대비
- 쉬운 말 켜기
- Smart Guide 켜기
- viewportMode:null → 자동 80%
- slowGuidance:false
- stepId: certificate.payment-method

원문:

증명서 종류, 발급 부수, 표시 항목과 수수료를 확인해 주세요. 내용이 맞으면 결제 방법을 눌러 가상 결제를 진행하세요.

검증:

1. Smart Guide가 실제 표시됨
2. 2페이지로 분할됨
3. 원문 67자 보존
4. 본문·버튼 잘림 없음
5. 줄 높이 25.6px 적용
6. 헤더 44px, 본문 약 52px 확보
7. 패널 상단 y=8px 유지
8. 기본 2페이지 15초, 약 7.5초 후 전환
9. 느린 2페이지 20초, 약 10초 후 전환
10. 한 페이지 기본 10초
11. 종료 후 쉬운 말 페이지·접힘 상태 복원

## 3. 기존 개선 사항 유지

360×667 쉬운 말 안내:

- 하단 60%: 2페이지
- 하단 70%: 2페이지
- 하단 80%: 4페이지
- 자동 80%: 4페이지

원문 보존, 버튼 겹침 없음, 상단 y=8px 유지.

스크롤 안내:

- 기본 모드: footer 위 12px
- 하단 70·80%: footer 위 약 12~13px
- 스크롤 끝에서 숨김
- 데모커피 주문 확인 바 위 12px
